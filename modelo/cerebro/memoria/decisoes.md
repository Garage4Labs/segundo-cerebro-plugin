# Decisões

Formato: `AAAA-MM-DD — decisão. **Por quê:** motivo.` Cada decisão vai na seção do seu assunto.
Antes de propor algo, o Claude confere aqui para não contradizer o que já foi decidido.
Para mudar uma decisão, registre a nova com o porquê e risque a antiga (~~assim~~), sem apagar.
